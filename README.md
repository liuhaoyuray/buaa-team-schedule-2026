# 北航志工部、实践部课表查询

按日期和时段查询空闲人员、课程安排和联系方式，包含一周总览、共同排期、个人课表、人员名录及工作名单。

访问地址：https://liuhaoyuray.github.io/buaa-team-schedule-2026/

## 使用

- **共同排期**：选择多位同学、教学周和所需时长，查找共同空闲时间；也可按可参加人数推荐时段。
- **工作名单**：在查询结果中勾选人员，复制联系方式或导出 CSV。更换时段后会重新计算名单中每人的状态。
- **显示模式**：右上角可在玻璃效果和清晰模式之间切换；使用深蓝、青绿、冰白配色。
- 工作名单与显示偏好保存在当前浏览器；缺失课表和不明确的安排仍显示待确认。

## 发布

仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
之后在 Actions 中运行“同步课表并发布网页”，或等待下一次推送。
成功发布后，以 Actions 的 deployment 链接为准。

## 自动更新

- 每次推送到 main 时运行；每小时第 17 分钟检查一次源平台，也可从 Actions 手动运行。
- 源平台有变化时，将页面、程序与整理后的课表数据保存进本仓库，然后发布 GitHub Pages；没有变化时不创建重复提交。
- GitHub 的定时任务可能延迟，自动同步通常不是即时的。
- 数据源：https://buaa-team-schedule-2026.liuhaoyuray.chatgpt.site/
- F 盘新文件仍需先整理并发布到源平台。云端任务不能直接读取本机 F 盘。

`public/` 为同步生成的网页；`scripts/` 和 `.github/workflows/` 为同步、发布配置。
下载原始课表和任职表的链接指向源平台，不将原始任职表另外提交进仓库。
同步过程不修改此 README 或其他人工维护文件。

## 数据规则

- 第一周从 2026 年 9 月 7 日开始；课程内明确的周次、单双周照常使用。
- 单周标题课表作为学期课表；同一人多份课表采用最新一份。
- “部员”和“学生干部”统一显示为“学生干部”。
- 2026 年秋季新加入的人员统一标注“2026年秋季学期新加入”。
- 刘浩宇、万释鸿、牛葳按设置在本学期默认无课；已登记的其他临时安排仍会保留。
- 退部人员不再纳入人员、个人课表和排期查询。
- 未交课表且未设置默认无课者不会算作空闲；考试、临时调课和未登记安排需联系本人确认。
- 在网页手动修改的联系方式与校历设置仅保存在当前浏览器，不会写入共享数据。

node scripts/sync-site.mjs
