# 北航志工部、实践部课表查询

按日期和时段查询空闲人员、课程安排和联系方式，包含一周总览、共同排期、个人课表、人员名录、工作名单及两校区值班草案。

访问地址：https://liuhaoyuray.github.io/buaa-team-schedule-2026/

## 使用

- **值班表**：分别生成学院路线下、沙河线上值班草案，按周一至周五的 1–2、3–5、6–7、8–10 节排布。每个固定班次会检查有效期内的每一次日期。
- **Excel 导出**：在“值班表”点击“导出 Excel（两部门）”，得到志工部、实践部两个工作表。每张表合并学院路和沙河，值班格内线上姓名后标“（线上）”。现直接采用上传的“26秋值班表.xlsx”两张表的格式，保留14行结构、原字体、边框、合并、行高列宽、部门信息和六行电话区。实际缺口在页面保留。
- **值班核对**：可核对校区、年级和本次参与人员，查看候选人的冲突日期、每人班次数与未排原因；支持复制、打印和导出两校区 CSV。核对设置仅保存在当前浏览器，可导出备份。
- **共同排期**：选择多位同学、教学周和所需时长，查找共同空闲时间；也可按可参加人数推荐时段。
- **工作名单**：在查询结果中勾选人员，复制联系方式或导出 CSV。更换时段后会重新计算名单中每人的状态。
- **显示模式**：右上角可在玻璃效果和清晰模式之间切换；使用深蓝、青绿、冰白配色。
- 工作名单与显示偏好保存在当前浏览器；缺失课表和不明确的安排仍显示待确认。

## 发布

仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
之后在 Actions 中运行“同步课表并发布网页”，或等待下一次推送。
成功发布后，以 Actions 的 deployment 链接为准。

## 自动更新

- 每次推送到 main 时运行；每小时第 17 分钟检查一次源平台，也可从 Actions 手动运行。
- 源平台有变化时，将页面、程序与整理后的课表数据保存进本仓库，然后发布 GitHub Pages；没有变化时不创建重复提交。
- GitHub 的定时任务可能延迟，自动同步通常不是即时的。
- 数据源：https://buaa-team-schedule-2026.liuhaoyuray.chatgpt.site/
- F 盘新文件仍需先整理并发布到源平台。云端任务不能直接读取本机 F 盘。

`public/` 为同步生成的网页；`scripts/` 和 `.github/workflows/` 为同步、发布配置。
课表下载链接及当前有效人员名单的 CSV 链接指向源平台，不将原始任职表另外提交进仓库。
同步过程不修改此 README 或其他人工维护文件。

## 数据规则

- 第一周从 2026 年 9 月 7 日开始；按北航 2026—2027 校历，第一学期第 19 周截至 2027 年 1 月 17 日，1 月 18 日起寒假。课程内明确的周次、单双周照常使用。
- 单周标题课表作为学期课表；同一人多份课表采用最新一份。
- “部员”和“学生干部”统一显示为“学生干部”。
- 2026 年秋季新加入的人员统一标注“2026年秋季学期新加入”。
- 刘浩宇、万释鸿、牛葳、张宸瑶、边琳杰按设置在本学期默认无课；已登记的其他临时安排仍会保留。
- 退部人员不再纳入人员、个人课表和排期查询。
- 原始 PDF 周次缺失或异常的课程，在受影响时段保留“待确认”，不推测缺失数字。
- 未交课表且未设置默认无课者不会算作空闲；考试、临时调课和未登记安排需联系本人确认。
- 在网页手动修改的联系方式与校历设置仅保存在当前浏览器，不会写入共享数据。

## 值班规则与资料状态

- 值班从所选日期开始，到第 17 周结束（2027-01-03）；第 18–19 周不值班，过去已经结束的安排不参与核验。
- 每个固定班次逐次检查整个值班期的课程与其他安排，任一次冲突或待确认即不可安排。
- 学院路：优先两个部门都有人、合计 3 人并均衡两种配置。大一、大二优先每人 2 班，大三允许 1–2 班，大四和研究生暂不安排。
- 沙河：每人目标 2 班，包括大四和研究生；每部门每格 1–2 人，优先两个部门各 1 人。
- **每人最多 2 班、最多 1 次早班；出现两个早班的方案直接作废。** 尽量分在不同天，不连班。
- 2026-10-17 已重新读取 F 盘，接入王显、朱岩课表。按部长确认，朱岩上交的表作为个人课表使用；补充的两校区人员信息已写入共享资料。
- 当前默认方案：学院路大一、大二均为 2 班，大三为 1–2 班，19 个时段有两个部门，双人配置 9:10；周五 3–5 节实践部仍缺人。沙河 18 人均为 2 班，共 36 人次，受空闲时段及早班限制仍缺 5 个部门时段。两校区默认方案均无两个早班、同日两班或连班。
- Excel 直接采用“26秋值班表.xlsx”两张表的格式；表头校正为秋季学期，8–10 节仍按课表的 18:15 截止。保留两字姓名的留空方式、部门公邮、办公室及电话，电话区不再重复加线上后缀。
- 学院路的万释鸿（周三1–2节）、张景涵（周四3–5节）、张宸瑶（周五3–5节）、陈家宝（周五6–7节）、边琳杰（周三8–10节）仅按示例位置展示，无需到岗，不计个人班次、实际人数或覆盖；部长不进入值班格。页面显示“仅展示”标签，Excel 相应单元格附批注。

- 年级按学号推定，可在页面核对。导出使用当前生效期、校区/年级核对及校历设置；浏览器手动修改仅本机保存。页面最下方列出了完整排班原则。

## 幸运抽奖

- 在导航栏进入“幸运抽奖”，支持全屏显示。沿用上传的抽奖文件：志愿者工作部35人、社会实践部29人，共64人；抽奖名单独立于当前课表人员名单。
- 可选择全部或单个部门，开始滚动后点击停止揭晓；默认不重复中奖，也可关闭限制。支持名单搜索、复制中奖记录和确认重置。
- 切换功能或刷新页面均恢复当前浏览器已保存的中奖记录；支持撤销上轮和CSV导出。
- `features/lottery/` 保存抽奖源文件。`scripts/integrate-lottery.mjs` 在每次课表同步后接入抽奖功能，源课表无变化时也会保留抽奖；原有按小时同步机制继续生效。
