志愿北京录入助手

支持添加团体成员、添加活动岗位志愿者、逐人录入时长和批量提交时长审批，可自动生成时长汇总图片与备注。

安装最新脚本

首次安装权限设置使用方法自动更新常见问题

1. 安装篡改猴

使用电脑上的 Edge 或 Chrome 打开这份教程。

  1. 打开篡改猴官方网站，选择与你浏览器对应的稳定版，进入扩展商店，点「获取」或「添加至浏览器」，再确认添加扩展。
  2. 安装完成后，点击浏览器右上角的扩展图标，将「篡改猴」固定到工具栏，方便以后打开管理面板。

2. 打开运行脚本所需的权限

  1. Edge 在地址栏输入 edge://extensions，Chrome 输入 chrome://extensions。
  2. 找到「篡改猴」，点「详细信息」。如果有「允许运行用户脚本」或「允许用户脚本」开关，请打开。较旧浏览器如果提示使用开发人员模式，就按提示回到扩展管理页打开「开发人员模式」。
  3. 在篡改猴的「网站访问权限」中允许它在志愿北京运行。使用特定网站设置时，添加 https://www.bv2008.cn/*；使用试运行网址时再添加 https://test1.bv2008.cn/*。

篡改猴管理面板如果仍显示「请启用允许用户脚本」，返回浏览器扩展详情检查开关，再刷新管理面板。

下图展示开关的位置，请将「允许运行用户脚本」打开。

3. 安装录入助手

  1. 确认篡改猴已启用后，点击本教程顶部的「安装最新脚本」。
  2. 浏览器会打开篡改猴安装确认页，核对名称为「志愿北京 · 批量录入助手」，点「安装」。已有旧版时，确认更新或重新安装同名脚本。
  3. 打开志愿北京，登录自己的团体账号并刷新网页，右上角会出现「批量录入」按钮。

如果点击安装链接只显示代码，可以下载脚本文件，再打开「篡改猴 → 管理面板 → 实用工具」，点击「导入」这一行的「选择文件」，选中下载的 .user.js 文件，最后在确认页安装。

按要办的事选择入口

  1. 添加团体成员。官网进入「志愿者管理 → 我的成员 → 正式成员」，打开「批量录入」。导入姓名、证件号码两列，核对团体后开始。
  2. 添加活动志愿者。在「我的活动」展开活动，在对应岗位点「招募」，进入「已录用」。导入姓名加志愿者编号或证件号码，核对活动和岗位后开始。
  3. 逐人录时长。进入活动岗位的「计时 → 时长录入」，打开助手的「录入时长」。活动名称和日期范围会自动从当前项目读取，备注同步生成；可按实际服务情况调整。日期取自官网允许录入的服务日期。选择「逐人录入时长」，导入姓名、编号或证件号码、拟录入时长三列。
  4. 预览证明。默认根据活动、团体、日期范围及名单自动生成时长汇总图片，点击「预览证明图片」，核对后勾选确认并开始。也可选择「上传已有证明图片」，使用原有服务材料。汇总单根据所填信息生成，不包含自动编造的签字、盖章或审批结果。姓名在官网被隐藏时，助手会自动点开小眼睛核对，再恢复隐藏。
  5. 批量提交时长审批。在同一面板选择「批量导入，提交上级审批」。名单、日期和证明的填写方法相同；助手自动检查历史记录、下载并填好官网模板、上传解析，然后按日期提交。无需跳转工作台。官网解析存在失败行、人数或时长不一致时，整批暂停。已提交审批会单独显示，等待上级审核，不会重复报批。

时长按每天最多 8 小时分配，按 0.5 小时递增。遇到官网标记已有时长、待审核或其他记录的日期会避开；切换日期后也会检查表单是否已带出旧记录。日期不足的剩余时长会留在明细里。

录时长依据官网当前账号权限和服务日期范围执行。汇总单能否作为证明，按所在团体的材料要求核对；需要已审核材料时，选择「上传已有证明图片」。PNG 或 JPG 格式，小于 3 MB。

Excel 可以第一行是总标题、第二行才是列名，助手会自动定位表头。时长列支持「总时长」「拟录入时长」「待录入时长」「服务时长」等，优先采用拟录入列；不把「已录入时长」当成本次申请值。支持 2.5、2小时30分、150分钟、02:30 及 Excel 时间格式，原值与解析后小时数并排显示。不符合半小时规则的值会提示原因，不自动取整。

文件下方显示采用的表头行、姓名列和时长列。识别不对时展开「识别列不对？在这里调整」，直接选择正确列，无需改原文件。缺列提示只针对当前选中的工作表，合计和重复表头会忽略；真正有问题的人员显示具体原因。已有处理进度时不允许悄悄更换识别列，防止错认人员或重复录入。

日期下拉框会自动展开并等待选中值生效，运行时无需手动点击日期。自动读取项目信息不完整时，面板会说明原因，可点「重新检查」重试。

以后如何更新

这个版本已经配置在线更新地址。首次安装后，篡改猴会按它的检查周期从本项目获取更新。新版发布后，刷新志愿北京即可运行已更新的脚本。

需要马上更新时，在篡改猴的「已安装脚本」中找到本助手，点「检查更新」；也可以再次点击本教程顶部的安装链接。篡改猴设置中，请保持「脚本更新」功能启用。

自动检查按浏览器和篡改猴的设置运行，发布后立即生效需要执行一次检查更新。正在录入时请先暂停，等当前提交完成后再刷新页面。

遇到问题时

  • 没有出现「批量录入」。检查篡改猴和本脚本是否都已启用、是否允许用户脚本及网站访问，再刷新志愿北京。
  • 显示请打开正式成员或计时页面。先在官网打开对应的后台页面，再点面板中的「重新检查」。
  • 结果显示「待核对」。先去官网核对对应人员、日期和时长，再回助手记录核对结果。
  • 刷新后继续。重新选择同一份原文件与录入方式，核对自动读取的活动、日期与保存进度，预览证明图片后继续。结果待核对时先核对官网记录；批量方式请查看「导入记录」，确认申请是否已提交。
